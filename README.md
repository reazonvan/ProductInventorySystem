# Система учёта товаров

WPF-приложение для управления товарами с использованием модульной архитектуры.

## Описание проекта

Приложение обеспечивает:
- Добавление, редактирование и удаление товаров
- Хранение информации о товарах (название, категория, количество, цена)
- Отображение статистики (общая сумма товаров, средняя цена по категории)
- Поиск товаров по названию или категории

## Структура проекта

### Модели данных (Models)
- **Product** - Товар (ProductID, Name, Category, Price, Quantity)
- **Category** - Категория (CategoryID, CategoryName)
- **Statistics** - Статистика (TotalProducts, AveragePrice, TotalValue)

### Сервисы (Services)
- **ProductService** - Сервис управления товарами (Singleton)

### Модули (Views)

#### 1. Главный интерфейс (MainWindow)
**Ответственный:** Лидер команды  
**Функциональность:**
- Главное окно с навигацией между модулями
- Переключение между разделами: Товары, Статистика, Поиск

#### 2. Модуль "Товары" (ProductsView)
**Ответственный:** Разработчик 1  
**Функциональность:**
- Просмотр списка товаров
- Добавление новых товаров
- Редактирование существующих товаров
- Удаление товаров

#### 3. Модуль "Статистика" (StatisticsView)
**Ответственный:** Разработчик 2  
**Функциональность:**
- Общая статистика по всем товарам
- Подсчёт общего количества товаров
- Расчёт средней цены
- Расчёт общей стоимости
- Статистика по выбранной категории

#### 4. Модуль "Поиск" (SearchView)
**Ответственный:** Разработчик 3  
**Функциональность:**
- Поиск товаров по названию
- Поиск товаров по категории
- Отображение результатов поиска

## Работа с Git

### Структура веток

```
main (master)
├── feature/main-interface      # Главный интерфейс
├── feature/products-module     # Модуль "Товары"
├── feature/statistics-module   # Модуль "Статистика"
└── feature/search-module       # Модуль "Поиск"
```

### Последовательность разработки

1. **Создание базовой структуры (main)**
   - Модели данных (Product, Category, Statistics)
   - Сервис ProductService

2. **Ветка feature/main-interface**
   - Главное окно с навигацией
   - Коммит: "Добавлен главный интерфейс с навигацией"

3. **Ветка feature/products-module**
   - Модуль управления товарами
   - Диалоговое окно добавления/редактирования
   - Коммит: "Добавлен модуль управления товарами"

4. **Ветка feature/statistics-module**
   - Модуль статистики
   - Общая статистика и по категориям
   - Коммит: "Добавлен модуль статистики"

5. **Ветка feature/search-module**
   - Модуль поиска товаров
   - Поиск по названию и категории
   - Коммит: "Добавлен модуль поиска товаров"

### Разрешение конфликтов

При возникновении конфликтов слияния:
1. Открыть конфликтующие файлы
2. Найти маркеры конфликта (`<<<<<<<`, `=======`, `>>>>>>>`)
3. Выбрать нужный код или объединить изменения вручную
4. Удалить маркеры конфликта
5. Добавить изменения: `git add <файл>`
6. Завершить слияние: `git commit`
